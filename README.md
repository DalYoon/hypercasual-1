# Ramen House · 라멘집

서버 없이 실행되는 아이소메트릭 2.5D 라멘집 경영 게임.
배포: https://dalyoon.github.io/hypercasual-1/

## 플레이
- 화면의 바닥을 누르면 장애물을 피해 이동합니다. 드래그, WASD, 방향키도 지원합니다.
- 금색 표시가 있는 초록 옷 캐릭터가 주인공입니다. 오른쪽 위 지도 버튼으로 전체 지도를 볼 수 있습니다.
- 재료 입고처에서 상자를 받고 주방으로 전달하면 주방장이 라멘을 만듭니다. 준비된 라멘을 받아 손님에게 전달합니다.
- 기본 운반/서빙 직원이 자동으로 일을 합니다. 손님은 빈 자리를 찾아 이동하고, 식사가 끝나면 돈을 냅니다.
- 발판에 서 있으면 코인을 지불해 강화합니다. 카운터(회전율/매출), 주방(조리), 쟁반(운반량), 운반/서빙 직원, 재료 입고의 여섯 종류이며 레벨 상한은 없습니다.
- 기존 `snowcamp_v3` 저장 데이터와 레벨을 유지합니다. 첫 전환 시 `snowcamp_v3_before_illustrated`에 원본을 한 번 백업합니다. 기존 3D 구현은 `game-3d-legacy.js`에 보존했습니다.

## 구현
- Canvas 2D. 그림의 바닥 접점으로 기물과 캐릭터를 함께 정렬합니다.
- 4석씩 3열, 분리된 주방, 실제 기물 충돌체와 연결된 A* 보행 그리드.
- 이동 경로는 대각선 모서리 통과를 막고, 하나로 연결된 보행 영역만 사용합니다.
- 배경과 기물은 `assets/shop`, 기존 캐릭터 알파 시트는 `assets/characters/alpha`입니다. 원본 캐릭터 시트는 그대로 보존했습니다.

## 현재 표현의 한계
캐릭터 시트는 단일 방향 걷기/작업 포즈입니다. 좌우 반전을 쓰며, 후면/착석 전용 동작은 없습니다. 카운터 그림에 그려진 라멘은 장식이고 실제 조리/서빙 상태는 캐릭터와 숫자로 별도 관리합니다.

이전 CC0/CC BY 3D 에셋은 기존 파일과 함께 보존되어 있습니다. 캐릭터 제작 기록: `assets/characters/README.md`.
